# 故障排查

> English: [Troubleshooting](troubleshooting.md)

先检查任务状态、阶段、错误类别和保存的疑点。保留原记录，以便区分失败尝试、重试和重新导出。

```bash
uv run folio --data-dir .folio status JOB_ID
uv run python scripts/audit_document_run.py \
  --root .folio --job JOB_ID --output .folio/audits/JOB_ID \
  --language zh-CN
```

审计命令离线执行，不会恢复生成。报告可能包含源材料原文，分享前应检查内容。耗时及调用次数的解释见[测试与验收](testing.zh-CN.md)。

## 连接与可选服务

| 现象 | 检查及处理 |
| --- | --- |
| 主模型连接或工具调用失败 | 核对 Base URL、模型 ID、凭据及原生工具调用支持。Base URL 不含 `/chat/completions`；仅返回文本或旧式 function-call 的响应不满足原生工具协议。 |
| Jev 或 Tavily 已填写但未启用 | 测试当前配置，显式勾选启用并保存。相关字段变化会使原测试资格失效；已保存配置复测失败会撤销该能力。 |
| 认证或计费错误 | 修正凭据或恢复账户可用后再重试。HTTP 401/403 和 402 不属于瞬态服务故障。 |
| 限流、临时断连或服务端错误 | 查看记录的重试和超时信息。恢复有次数及时间边界，服务持续不可用仍可能终止任务。 |
| 容量测量失败 | 核对模型元信息、分词容量接口和输入输出限制。字符数较少不能证明请求适合模型窗口。 |

不同操作采用不同判断路由。启用判断模型后的严格相关性筛选遇到服务失败，不会静默改用主 LLM；连接探测成功也不能证明后续每个请求都满足容量限制。参见[上下文与容量](context-and-capacity.zh-CN.md)。

## 目录规划与恢复

检查所有校验位置：同级重名、重复 ID、层级错误、缺少写作要求和覆盖不完整可能同时出现。修复后的候选仍需最终校验和预览检查；不能通过接受截断 JSON 或跳过校验获得目录。

遇到超时时，如诊断信息可用，应结合传输阶段、耗时和已接收字符数，区分连接、等待首段及流式传输延迟。缺少这些信息的旧记录不能证明某个具体网络原因。`length_limit` 表示输出未完成，应检查配置的输出额度。

修正原因后，使用当前工作区的重试或继续操作。从资料重新规划与修改现有目录的范围不同，应在正文生成前检查并确认结果。目录预览成功只验证规划与预览导出。参见[目录规划](outline-planning.zh-CN.md)。

## 研究不完整或待确认

发现来源、提取文字与核实覆盖是不同状态。文件可读或结构节点已列出，不证明每一页、Sheet、表格或图片都已检查。PDF 书签表达页范围，边界页可能重叠；OCR 文字仍须与原件核对。判断缺口是否属于材料缺失前，先查看本次范围和剩余覆盖义务。

研究镜像或转换工具缺失时，应补齐执行环境。Folio 不会退回宿主机执行生成的研究代码。沙箱配置、原页查看、OCR 和派生产物来源链见[业务 Agent 研究](agent-research.zh-CN.md)。

`needs_confirmation` 导出保留草稿及未决疑点。应查看疑点列表，通过工作区提供所需答复。DOCX 可下载不代表审阅通过；容量或调用额度耗尽可能留下正文完整、检查未完成的草稿。不要为获得发布状态而删除疑点或重新标记建议来源。

## 来源与红字

红字表示 `origin=model_proposal`，即缺少充分依据的业务建议。有证据的正文也可能经过 LLM 写作，因此颜色表达来源性质，不表示是否使用了模型。

同时检查引用完整性和语义。标为有证据的事实块没有引用，或引用无法对应保存的证据时，应进一步核查；引用有效仍不证明原文支持该结论。标题和空白数据单元格本身不构成业务事实陈述。

重排报告的 `provenance` 包含建议块数量、缺引用的块和无效引用。该报告不做语义审阅，也不重新分类旧正文。修改内容时，应继续区分原始项目资料、公开资料、派生结果和模型建议。

## 字体、列表、表格与分页

检查实际 Word 文档及可用的分页 PDF，确认：

- 所需字体已安装，正文和目录条目均使用预期字体；主题字体及字符样式可能影响渲染。
- 分页或 Word 更新域之后，标题层级、目录缩进、页码、页眉和页脚仍一致。
- 列表换行保留悬挂缩进，子项编号正确；小数和版本号仍作为普通文字。
- 表格不超出页面边界，保留必需表头、列宽及有意义的强调格式；不要为清除示例格式而删除全部彩色或斜体文字。
- 必需配图齐全、清晰，并对应当前正文版本；红色建议文字保留来源标记。

当前生成流程不执行最终 Jev 页面评分。自动格式检查及导出成功不能代替交付页面检查。参见[配图说明](illustrations.zh-CN.md)和[资料与排版](source-materials-and-layout.zh-CN.md)。

对已完成的任务（`published`、`draft` 或 `needs_confirmation`），可直接从保存内容另行导出，不调用模型：

```bash
uv run folio --data-dir .folio reformat JOB_ID \
  --output-dir .folio/exports/reformatted \
  --require-pagination
```

使用与原产物分离的新输出目录。`--require-pagination` 要求分页环境可用；只有接受未分页导出时才省略它。检查返回的排版报告和 `provenance` 摘要。重排保留已存业务状态，可能复用兼容的格式记录；它不能补足缺失证据，也不会产生新的语义审阅。
