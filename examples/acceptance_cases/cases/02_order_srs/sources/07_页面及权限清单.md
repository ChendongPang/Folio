# 工作台及权限交互清单

## 客服订单详情

必须并排显示订单、支付、履约三组状态以及每笔退款状态；时间线展示支付尝试、预占、补偿、退款、包裹事件。金额卡分商品实付、运费、已退、处理中占用和可退金额。普通客服查看客户手机号与地址脱敏结果；查完整数据需单独授权并审计。

## 退款申请与审核

客服选择订单行和件数，系统从固定份额计算金额，禁止任填超过可退额。金额大于50000分进入财务审核；显示同单处理中申请，避免人工重复批准。申请被渠道受理后页面显示退款处理中，不显示退款成功。
重复点击提交返回同一退款号；请求超时提供查询进度，不建议用户新建一笔相同申请。失败原因和人工处理入口应保留，审核操作需理由与权限。

## 门店自提核销

只允许本店店员输入或扫码核销；已核销码重复操作不再扣减库存，错误门店返回权限或归属错误。员工不可直接修改核销时间，管理员纠错须单独审计流程，具体流程待确认。
