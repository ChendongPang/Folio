# 青禾集团一体化平台 / 采购协同 / 采购退回 / M03-R10

## 适用边界与责任

本卡为一期采购协同域的采购退回，编号M03-R10。责任角色：采购专员；操作类型：业务或治理写入。租户、组织范围、公共性能和写请求重试规范见1501_总体范围与术语.docx。
本卡只授权下面明确的业务行为；审批责任、前后状态码映射及跨对象原子边界如未给出，应保留待确认，不能凭领域状态列表自行补成已批准流程。

## 动作输入与前置条件

实际输入：收货记录、物料批次、退回数量、原因。
前置条件：退回数量属于该次收货且尚可退回，质量结论或业务依据存在。

## 动作与预期产物

处理行为：建立退货单并关联原订单及库存出库依据，不先直接扣采购金额。
成功产物及业务变化：输出退货申请与待仓库执行任务，实际出库后核销相应数量。

## 状态、例外与完成条件

前后业务变化按“动作与预期产物”描述；未明示的具体状态跳转和批准人配置列为待确认，不推定按枚举先后自动跳转。
本域共享约束引用0301_采购协同_采购申请.md“状态、例外与完成条件”；不在每个动作重复抄写。
异常与边界：不能退超过净收货量，已消耗或冻结批次需先处理关联约束。
