# 青禾集团一体化平台 / 组织权限 / 组织建档 / M01-R01

## 适用边界与责任

本卡为一期组织权限域的组织建档，编号M01-R01。责任角色：组织管理员；操作类型：业务或治理写入。租户、组织范围、公共性能和写请求重试规范见1501_总体范围与术语.docx。
本卡只授权下面明确的业务行为；审批责任、前后状态码映射及跨对象原子边界如未给出，应保留待确认，不能凭领域状态列表自行补成已批准流程。

## 动作输入与前置条件

实际输入：组织编码、组织名称、上级组织、启用日期。
前置条件：上级组织存在且当前用户有维护权限；新组织编码尚未占用。

## 动作与预期产物

处理行为：新建组织档案并绑定父节点；不从上级自动复制全部业务权限。
成功产物及业务变化：返回新组织编号及待复核档案；组织启用前不得承接正式业务。

## 状态、例外与完成条件

前后业务变化按“动作与预期产物”描述；未明示的具体状态跳转和批准人配置列为待确认，不推定按枚举先后自动跳转。
组织权限领域状态为草拟、待复核、已生效、已撤销。这是该域不同对象可能使用的状态集合，不代表所有动作共用同一线性状态机。
权限仅按组织与岗位交集授予；跨区域授权必须由接收区域管理员复核
异常与边界：拒绝重复编码及以自身作为上级，保留输入供更正。
