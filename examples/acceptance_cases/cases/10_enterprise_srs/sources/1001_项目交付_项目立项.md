# 青禾集团一体化平台 / 项目交付 / 项目立项 / M10-R01

## 适用边界与责任

本卡为一期项目交付域的项目立项，编号M10-R01。责任角色：项目经理；操作类型：业务或治理写入。租户、组织范围、公共性能和写请求重试规范见1501_总体范围与术语.docx。
本卡只授权下面明确的业务行为；审批责任、前后状态码映射及跨对象原子边界如未给出，应保留待确认，不能凭领域状态列表自行补成已批准流程。

## 动作输入与前置条件

实际输入：项目名称、业务目标、责任人、范围。
前置条件：立项依据和责任组织明确。

## 动作与预期产物

处理行为：生成项目编号并记录首期范围与不包含事项，尚未批准资源不作已落实承诺。
成功产物及业务变化：输出立项档案及待确认约束。

## 状态、例外与完成条件

前后业务变化按“动作与预期产物”描述；未明示的具体状态跳转和批准人配置列为待确认，不推定按枚举先后自动跳转。
项目交付领域状态为已立项、执行中、待验收、已结项。这是该域不同对象可能使用的状态集合，不代表所有动作共用同一线性状态机。
范围变更批准前不得修改已确认里程碑；变更后保留原基线和新基线
异常与边界：目标或责任人不明确时保留草案，不自动形成交付承诺。
