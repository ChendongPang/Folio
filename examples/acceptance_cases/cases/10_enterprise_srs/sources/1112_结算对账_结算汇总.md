# 青禾集团一体化平台 / 结算对账 / 结算汇总 / M11-R12

## 适用边界与责任

本卡为一期结算对账域的结算汇总，编号M11-R12。责任角色：结算专员；操作类型：只读查询/呈现。租户、组织范围、公共性能和写请求重试规范见1501_总体范围与术语.docx。
此动作只读取或呈现既有资料，不推进业务状态，不申请业务审批，不套用人工接单时限。已有查询授权与数据范围检查仍须执行；必要访问审计与结果文件不改变原业务对象。

## 动作输入与前置条件

实际输入：主体、币种、期间、确认状态。
前置条件：具备查询范围权限，统计口径明确。

## 动作与预期产物

处理行为：分别汇总已确认、待确认、已申请和已支付等已存在字段；没有支付事实则标缺失。
成功产物及业务变化：输出分币种只读汇总及明细核对，不生成结算确认或付款。

## 状态、例外与完成条件

本动作无业务状态转换；返回无结果、权限不足或证据不完整时，不创建草稿业务单或等待审批单。
本域共享约束引用1101_结算对账_对账建单.md“状态、例外与完成条件”；不在每个动作重复抄写。
异常与边界：无汇率不跨币种折算，不能把付款申请当实际付款。
