# 青禾集团一体化平台 / 采购协同 / 需求合并 / M03-R02

## 适用边界与责任

本卡为一期采购协同域的需求合并，编号M03-R02。责任角色：采购专员；操作类型：业务或治理写入。租户、组织范围、公共性能和写请求重试规范见1501_总体范围与术语.docx。
本卡只授权下面明确的业务行为；审批责任、前后状态码映射及跨对象原子边界如未给出，应保留待确认，不能凭领域状态列表自行补成已批准流程。

## 动作输入与前置条件

实际输入：来源需求编号、物料规格、交付地点、需求日期。
前置条件：来源需求尚未转正式订单且属于可合并范围。

## 动作与预期产物

处理行为：仅合并相同物料规格、兼容交付条件的需求，保留来源行与数量分摊。
成功产物及业务变化：输出合并需求及每条来源映射，撤回合并可追到原需求。

## 状态、例外与完成条件

前后业务变化按“动作与预期产物”描述；未明示的具体状态跳转和批准人配置列为待确认，不推定按枚举先后自动跳转。
本域共享约束引用0301_采购协同_采购申请.md“状态、例外与完成条件”；不在每个动作重复抄写。
异常与边界：不同规格或已下单行不得强行合并，不能丢失各自预算来源。
