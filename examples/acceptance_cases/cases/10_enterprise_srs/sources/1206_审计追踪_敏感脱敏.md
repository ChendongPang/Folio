# 青禾集团一体化平台 / 审计追踪 / 敏感脱敏 / M12-R06

## 适用边界与责任

本卡为一期审计追踪域的敏感脱敏，编号M12-R06。责任角色：内部审计员；操作类型：只读查询/呈现。租户、组织范围、公共性能和写请求重试规范见1501_总体范围与术语.docx。
此动作只读取或呈现既有资料，不推进业务状态，不申请业务审批，不套用人工接单时限。已有查询授权与数据范围检查仍须执行；必要访问审计与结果文件不改变原业务对象。

## 动作输入与前置条件

实际输入：查询或导出结果、字段分类、查看人权限。
前置条件：字段敏感分类与查看权限可识别。

## 动作与预期产物

处理行为：在呈现层隐藏或掩码超出权限的字段，保留原事件供获授权人员核查。
成功产物及业务变化：输出按权限处理的只读视图，不能改写原始证据。

## 状态、例外与完成条件

本动作无业务状态转换；返回无结果、权限不足或证据不完整时，不创建草稿业务单或等待审批单。
本域共享约束引用1201_审计追踪_事件采集.md“状态、例外与完成条件”；不在每个动作重复抄写。
异常与边界：分类规则缺失时保留待配置，不能默认所有敏感内容可公开。
