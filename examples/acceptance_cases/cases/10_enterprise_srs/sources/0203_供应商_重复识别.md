# 青禾集团一体化平台 / 供应商 / 重复识别 / M02-R03

## 适用边界与责任

本卡为一期供应商域的重复识别，编号M02-R03。责任角色：供应商专员；操作类型：只读查询/呈现。租户、组织范围、公共性能和写请求重试规范见1501_总体范围与术语.docx。
此动作只读取或呈现既有资料，不推进业务状态，不申请业务审批，不套用人工接单时限。已有查询授权与数据范围检查仍须执行；必要访问审计与结果文件不改变原业务对象。

## 动作输入与前置条件

实际输入：供应商名称、税号、区域、历史别名。
前置条件：用户仅能查询授权范围内供应商。

## 动作与预期产物

处理行为：以税号精确匹配为主、名称相似为候选，显示导致匹配的字段。
成功产物及业务变化：输出可能重复档案列表，不自动合并或修改准入状态。

## 状态、例外与完成条件

本动作无业务状态转换；返回无结果、权限不足或证据不完整时，不创建草稿业务单或等待审批单。
本域共享约束引用0201_供应商_供应商登记.md“状态、例外与完成条件”；不在每个动作重复抄写。
异常与边界：跨区候选仅展示获授权字段；名称相似不能被断言为同一主体。
