# 青禾集团一体化平台 / 质量管理 / 返工评审 / M06-R08

## 适用边界与责任

本卡为一期质量管理域的返工评审，编号M06-R08。责任角色：质量工程师；操作类型：业务或治理写入。租户、组织范围、公共性能和写请求重试规范见1501_总体范围与术语.docx。
本卡只授权下面明确的业务行为；审批责任、前后状态码映射及跨对象原子边界如未给出，应保留待确认，不能凭领域状态列表自行补成已批准流程。

## 动作输入与前置条件

实际输入：不合格批次、缺陷、返工方案、责任人。
前置条件：批次仍在受控范围，返工技术方案可用。

## 动作与预期产物

处理行为：评估返工可行性及后续检验要求，保存采用方案版本。
成功产物及业务变化：输出返工决定和复检要求，不把评审通过当质量放行。

## 状态、例外与完成条件

前后业务变化按“动作与预期产物”描述；未明示的具体状态跳转和批准人配置列为待确认，不推定按枚举先后自动跳转。
本域共享约束引用0601_质量管理_来料检验.md“状态、例外与完成条件”；不在每个动作重复抄写。
异常与边界：返工方案不明或影响无法判断时保留待决，不默认恢复合格。
