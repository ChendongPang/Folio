# 青禾集团一体化平台 / 组织权限 / 部门调整 / M01-R02

## 适用边界与责任

本卡为一期组织权限域的部门调整，编号M01-R02。责任角色：组织管理员；操作类型：业务或治理写入。租户、组织范围、公共性能和写请求重试规范见1501_总体范围与术语.docx。
本卡只授权下面明确的业务行为；审批责任、前后状态码映射及跨对象原子边界如未给出，应保留待确认，不能凭领域状态列表自行补成已批准流程。

## 动作输入与前置条件

实际输入：组织编码、部门编码、原上级、新上级、生效日期。
前置条件：部门存在，新上级位于获授权的组织范围。

## 动作与预期产物

处理行为：检查新父节点不是本部门的子孙节点，记录原、新隶属关系和生效日期。
成功产物及业务变化：输出部门调整版本及受影响人员名单；既有单据仍保留当时组织快照。

## 状态、例外与完成条件

前后业务变化按“动作与预期产物”描述；未明示的具体状态跳转和批准人配置列为待确认，不推定按枚举先后自动跳转。
本域共享约束引用0101_组织权限_组织建档.md“状态、例外与完成条件”；不在每个动作重复抄写。
异常与边界：有组织环路或未获跨区授权时拒绝提交，不先移动人员。
