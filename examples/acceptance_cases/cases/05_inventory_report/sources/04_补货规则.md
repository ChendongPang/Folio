# 本次分析采用的补货计算规则

## 固定计算方法

本次仅使用9月30个自然日的净销量计算平均日需求d=净销量/30；不做季节调整，不引入未提供的预测模型。公司级合并计算四个SKU，不直接对两仓各自下单。
再订货点=d×(采购提前期天数+安全覆盖天数)。库存位置严格小于再订货点时触发补货；相等时不触发。目标库存=d×目标覆盖天数。触发后建议采购量=向上取整至包装倍数(max(0,目标库存−库存位置))；未触发时建议量为0。
中间平均日需求、再订货点和目标库存保留精确分数或足够精度，不先四舍五入。最终采购数量必须为非负整数且是包装倍数。采购预算=建议采购量×标准单位成本，只是按标准成本估算，不代表供应商报价。

## 分析解释要求

高销售量不必然意味着最高毛利，低库存也不必然触发采购；必须连同退款、预留、在途和包装倍数解释。表格显示SKU、净销量、净销售额、净毛利、日需求、库存位置、再订货点、建议采购量和预算。
需要按仓库展示净销量与净销售额，但不得把公司级补货量不加依据地拆到两仓。无仓间运输成本和仓别服务目标时，仓间调拨只列待补数据。
